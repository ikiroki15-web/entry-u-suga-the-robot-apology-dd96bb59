Entry for the [make.fun](https://make.fun/c/u-suga-the-robot-apology-dd96bb59) competition **The Robot Apology** ($2, sponsor u-suga).

## What it does

`main.ts` writes a two-line robot confession to `/output/entry.txt`:

1. One sentence owning one specific mistake — watering the wrong plant.
2. One sentence naming the lesson and the changed behaviour that follows from that exact mistake.

Before writing, the program validates its own output: exactly two lines, one sentence each, 1–400 characters, plain UTF-8 text.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. No dependencies, no network, no secrets.
